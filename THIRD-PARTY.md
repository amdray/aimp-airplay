- crosstools `dc6c109e69bb5bf414603c69e64bc1b855875916`.

Original copyright notices are preserved in source files. License texts accompany
the binary packages in `licenses`. The GitHub build links to the source revision
used to build the packages. The build workflow fetches libraop and its submodules
at the listed revisions.
MinGW platform/packing adjustments are generated by cmake/raop.cmake. Original
SDK headers are downloaded from the official AIMP site by tools/Prepare-Sdk.ps1,
which verifies the pinned SDK 5.40 archive before extraction.
The project additions in src, tools, tests and cmake may be used under GPLv3 or later.
